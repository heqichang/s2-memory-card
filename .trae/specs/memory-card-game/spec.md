# 记忆卡片翻转游戏 - 产品需求文档

## Overview
- **Summary**: 一款基于 Web 的记忆卡片翻转配对游戏，玩家需要在倒计时结束前翻开所有卡片并找到所有配对。每次只能翻开两张卡片，若图案相同则配对成功并保持翻开状态，若不同则自动翻回背面。
- **Purpose**: 提供休闲益智的小游戏体验，锻炼玩家的记忆力和注意力。
- **Target Users**: 喜欢休闲益智游戏的普通用户，可用于打发时间或脑力训练。

## Goals
- 实现经典记忆配对游戏核心玩法
- 提供倒计时机制，增加游戏紧张感和挑战性
- 流畅的卡片翻转动画效果
- 清晰的游戏状态反馈（成功、失败、得分等）
- 支持游戏重新开始

## Non-Goals (Out of Scope)
- 多人在线对战功能
- 游戏排行榜系统
- 用户账户和数据持久化
- 多种难度级别选择（仅提供默认难度）
- 音效和背景音乐
- 移动端适配优化（优先桌面端体验）

## Background & Context
- 项目从零开始，使用纯前端技术实现
- 采用 HTML + CSS + JavaScript 原生实现，无需额外框架
- 目标是创建一个轻量级、可直接运行的单页游戏应用

## Functional Requirements
- **FR-1**: 游戏初始化时随机排列卡片，所有卡片均为背面朝上
- **FR-2**: 点击卡片可翻转显示正面图案
- **FR-3**: 每次最多同时翻开两张卡片
- **FR-4**: 若翻开的两张卡片图案相同，则配对成功，卡片保持正面朝上
- **FR-5**: 若翻开的两张卡片图案不同，则短暂显示后自动翻回背面
- **FR-6**: 游戏开始时启动倒计时
- **FR-7**: 倒计时结束时游戏结束，判定为失败
- **FR-8**: 在倒计时内成功配对所有卡片则游戏胜利
- **FR-9**: 显示当前已配对成功的对数
- **FR-10**: 提供重新开始按钮，可重置游戏

## Non-Functional Requirements
- **NFR-1**: 卡片翻转动画流畅自然，过渡时间约 0.3 秒
- **NFR-2**: 页面加载时间 < 1 秒
- **NFR-3**: 游戏界面布局居中，视觉舒适
- **NFR-4**: 代码结构清晰，易于维护和扩展
- **NFR-5**: 兼容主流现代浏览器（Chrome、Firefox、Safari、Edge）

## Constraints
- **Technical**: 纯 HTML/CSS/JavaScript 实现，不使用第三方框架
- **Business**: 单页面应用，无需后端服务
- **Dependencies**: 无外部依赖库

## Assumptions
- 默认使用 16 张卡片（8 对）进行游戏
- 倒计时默认设置为 60 秒
- 使用 emoji 或数字作为卡片图案
- 游戏在桌面浏览器中运行

## Acceptance Criteria

### AC-1: 游戏初始化
- **Given**: 玩家打开游戏页面
- **When**: 页面加载完成
- **Then**: 所有卡片以背面朝上随机排列，倒计时显示初始值，已配对数为 0
- **Verification**: `programmatic`
- **Notes**: 验证卡片数量为 16 张，8 对不同图案

### AC-2: 卡片翻转交互
- **Given**: 游戏处于进行中状态
- **When**: 玩家点击一张背面朝上的卡片
- **Then**: 卡片以翻转动画显示正面图案
- **Verification**: `human-judgment`
- **Notes**: 动画效果流畅自然

### AC-3: 配对成功
- **Given**: 已翻开一张卡片，再点击另一张图案相同的卡片
- **When**: 第二张卡片翻开后
- **Then**: 两张卡片保持正面朝上，已配对数 +1
- **Verification**: `programmatic`

### AC-4: 配对失败
- **Given**: 已翻开一张卡片，再点击另一张图案不同的卡片
- **When**: 第二张卡片翻开后短暂延迟（约 1 秒）
- **Then**: 两张卡片自动翻回背面
- **Verification**: `programmatic`

### AC-5: 限制同时翻开数量
- **Given**: 已翻开两张卡片
- **When**: 玩家点击第三张卡片
- **Then**: 第三张卡片不响应点击，保持背面朝上
- **Verification**: `programmatic`

### AC-6: 倒计时运行
- **Given**: 游戏开始
- **When**: 时间流逝
- **Then**: 倒计时数字逐秒递减
- **Verification**: `programmatic`

### AC-7: 倒计时结束游戏失败
- **Given**: 倒计时归 0
- **When**: 仍有未配对的卡片
- **Then**: 显示游戏失败提示，所有卡片不再响应点击
- **Verification**: `programmatic`

### AC-8: 全部配对游戏胜利
- **Given**: 倒计时内
- **When**: 所有卡片都成功配对
- **Then**: 显示游戏胜利提示，倒计时停止
- **Verification**: `programmatic`

### AC-9: 重新开始
- **Given**: 游戏处于任何状态
- **When**: 玩家点击重新开始按钮
- **Then**: 卡片重新随机排列，所有卡片翻回背面，倒计时重置，已配对数清零
- **Verification**: `programmatic`

### AC-10: 游戏界面美观
- **Given**: 游戏页面
- **When**: 正常浏览
- **Then**: 布局居中对称，卡片样式统一，整体视觉效果舒适
- **Verification**: `human-judgment`

## Open Questions
- [ ] 卡片图案使用 emoji 还是数字？默认使用 emoji
- [ ] 倒计时时长设置为多少秒？默认 60 秒
- [ ] 卡片数量多少对合适？默认 8 对（16 张）
